How to run

  1. Download the .exe above (Windows 10/11).
  2. Connect the tester to the PC by USB.
  3. Double-click the .exe. No install is needed.
  4. The version is shown in the app and written into every report. Always use the latest version from this page.
Windows warning? If Windows SmartScreen says "Windows protected your PC", click More info → Run anyway. The app is not code-signed yet.
