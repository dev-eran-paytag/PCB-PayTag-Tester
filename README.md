# mini-A Tester — downloads

Windows test console for the mini-A PCB (firmware bundled inside the app).

## ⬇ Download
**Download page: https://dev-eran-paytag.github.io/PCB-PayTag-Tester/**
or the latest release directly: [Releases → latest](https://github.com/dev-eran-paytag/PCB-PayTag-Tester/releases/latest)

1. Download `mini_a_test_console-vX.Y.Z.exe` (Windows 10/11).
2. Connect the tester by USB.
3. Double-click the `.exe`. No install is needed.

If Windows SmartScreen says "Windows protected your PC", click **More info → Run anyway**
(the app is not code-signed yet).

Always use the latest version. The version is shown in the app and written into every report.

---
Only stable, tested versions are published here, automatically, by the release build.
